# Allow Special Keys

[中文](#中文) | [English](#english) | [한국어](#한국어)

---

## 中文

**Allow Special Keys** 是一个《冰与火之舞》(A Dance of Fire and Ice) 的 Mod，用于拦截 Windows 系统级快捷键，并允许将特殊按键（Win、Alt、Ctrl、F12）作为游戏内按键使用。

### 功能

- **拦截 Win 键** — 防止按下 Win 键弹出开始菜单
- **拦截 Alt+Tab / Alt+F4 / Alt+Esc** — 防止游戏切出
- **拦截 Alt+Enter** — 防止全屏切换
- **拦截 Ctrl+Esc** — 防止打开开始菜单
- **游戏内特殊按键** — 允许 Win/Alt/Ctrl 作为游戏按键绑定和识别
- **F12 游戏按键** — 允许 F12 作为游戏按键使用
- **支持 JipperKeyViewer** — 正确识别 Alt 和 Win 按键
- **多语言 UI** — 中文 / English / 한국어

### 安装

1. 确保已安装 [Unity Mod Manager](https://www.nexusmods.com/site/mods/21) (UMM)
2. 将 `AllowSpecialKeys` 文件夹放入 `A Dance of Fire and Ice/Mods/` 目录
3. 启动游戏，在 UMM 菜单中启用 Allow Special Keys

### 使用方法

在 UMM 的 Mod 菜单中找到 **Allow Special Keys**，根据需要切换开关：

| 选项 | 说明 |
|------|------|
| 拦截 Windows 键 | 阻止 Win 弹出开始菜单 |
| 拦截 Alt+Tab / Alt+F4 / Alt+Esc | 阻止游戏切出 |
| 拦截 Alt+Enter | 阻止全屏切换 |
| 拦截 Ctrl+Esc | 阻止打开开始菜单 |
| 允许特殊键作为游戏按键 | Win/Alt/Ctrl 可作为游戏内按键使用 |
| 允许 F12 作为游戏按键 | F12 可作为游戏内按键使用 |

点击 **应用** 保存设置。

## English

**Allow Special Keys** is a mod for *A Dance of Fire and Ice* that blocks Windows system-wide hotkeys and allows special keys (Win, Alt, Ctrl, F12) to be used as in-game keys.

### Features

- **Block Win key** — prevent Start menu from opening
- **Block Alt+Tab / Alt+F4 / Alt+Esc** — prevent alt-tabbing out
- **Block Alt+Enter** — prevent fullscreen toggle
- **Block Ctrl+Esc** — prevent Start menu from opening
- **In-game special keys** — allows Win/Alt/Ctrl to be bound and detected in-game
- **F12 as gameplay key** — allows F12 to be used as a gameplay key
- **JipperKeyViewer support** — correctly detects Alt and Win key presses
- **Multi-language UI** — 中文 / English / 한국어

### Installation

1. Make sure [Unity Mod Manager](https://www.nexusmods.com/site/mods/21) (UMM) is installed
2. Place the `AllowSpecialKeys` folder into `A Dance of Fire and Ice/Mods/`
3. Launch the game, enable Allow Special Keys in the UMM menu

### Usage

Open the UMM mod menu and find **Allow Special Keys**. Toggle as needed:

| Option | Description |
|--------|-------------|
| Block Windows key | Prevents Win key from opening the Start menu |
| Block Alt+Tab / Alt+F4 / Alt+Esc | Prevents alt-tabbing out of game |
| Block Alt+Enter | Prevents fullscreen toggle |
| Block Ctrl+Esc | Prevents Start menu from opening |
| Allow special keys as gameplay keys | Win/Alt/Ctrl can be used in-game |
| Allow F12 as gameplay key | F12 can be used in-game |

Click **Apply** to save settings.

## 한국어

**Allow Special Keys**는 *A Dance of Fire and Ice*의 모드로, Windows 시스템 단축키를 차단하고 특수 키(Win, Alt, Ctrl, F12)를 게임 내 키로 사용할 수 있게 합니다.

### 기능

- **Win 키 차단** — 시작 메뉴 열림 방지
- **Alt+Tab / Alt+F4 / Alt+Esc 차단** — 게임 이탈 방지
- **Alt+Enter 차단** — 전체화면 전환 방지
- **Ctrl+Esc 차단** — 시작 메뉴 열림 방지
- **게임 내 특수 키** — Win/Alt/Ctrl을 게임 키로 바인딩 가능
- **F12 게임 키** — F12를 게임 키로 사용 가능
- **JipperKeyViewer 지원** — Alt 및 Win 키 정확히 인식
- **다국어 UI** — 中文 / English / 한국어

### 설치

1. [Unity Mod Manager](https://www.nexusmods.com/site/mods/21) (UMM) 설치 필요
2. `AllowSpecialKeys` 폴더를 `A Dance of Fire and Ice/Mods/`에 복사
3. 게임 실행 후 UMM 메뉴에서 Allow Special Keys 활성화
